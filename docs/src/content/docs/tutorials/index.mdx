This tier teaches through the task. The rail runs against a real data home with
real collected seasons, and its arc mirrors the system's own layers: stand up a
season, read a raw page, trace an identity, interrogate the digest, break a
gate, produce evidence, then run and audit the whole machine.

One conceit governs every lab: **the system grades the student.** Checkpoints
end with a command whose output is the answer key, never a prose answer. Start
with the [syllabus](syllabus/) for the competency map, the three lab modes, and
the reading paths.
