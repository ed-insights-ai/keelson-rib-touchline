College soccer publishes nearly everything a scout needs: schedules, rosters,
player statistics, and a box score for every match, on the athletics sites
every programme already maintains. What almost no programme below the top
divisions has is the analyst to assemble it.

Touchline is that analyst. It collects what schools publish and archives every
page verbatim, reconciles the parses into canonical records, computes every
number deterministically, and lets a language model write the scouting prose
under an evidence standard: every figure computed by code, every claim cited,
every gap named. The season board shows what is held, what is missing, and why.

Touchline is a [Keelson](https://danielscholl.github.io/keelson/) rib: it
installs into the harness you already run and reuses what the harness owns, its
providers, the workflow engine, and the board surface. Everything here is what
Touchline adds.

This site serves two readers through the same pages. An operator runs the rib:
collections, the board, reports. A student of data science reads the same
system as a working curriculum: scraping under proof, identity resolution,
missingness, deterministic analysis, and how to put a language model inside a
data system without letting it invent a number.
