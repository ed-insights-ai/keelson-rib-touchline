## The eight learnings

The document closes with eight learnings. Each now has a canonical page here,
and every other mention on the site links to that page.

1. **Put a gate after every generative step.** A completion claim is a request to be checked, never an exit condition: [Gate after every generative step](../gate-after-every-generative-step/).
2. **Draw the determinism boundary early; never let a number cross it.** [The determinism boundary](../../concepts/the-determinism-boundary/).
3. **Use the model as a reader, never as a source.** [The model as reader, never a source](../the-model-as-reader/).
4. **Grade evidence; never delete it.** A refuted claim, downgraded and kept, protects every future run: [Evidence, not recall](../../concepts/evidence-not-recall/).
5. **Contracts beat examples.** Written rules plus validators reproduce quality; a reference sample imprints: [Contracts beat examples](../contracts-not-examples/).
6. **Absence is data.** Compute the gaps and print them, so a caveat heals itself: [Absence is data](../../concepts/absence-is-data/).
7. **Archive primary sources; treat every store as derived.** [The raw archive as system of record](../raw-archive-as-system-of-record/).
8. **A report is a run, not a document.** [A briefing is a run, not a document](../a-briefing-is-a-run/).

## The dated measurements

Two point-in-time measurements from the document are collected here. The
generative-surface figure lives only on this page; the language-reuse figure
is also part of the record in
[Contracts beat examples](../contracts-not-examples/). Outside the design
tier, pages link to these numbers rather than restating them.

**The generative surface, August 2026 Harding run.** Of the words on the
briefing's pages, the model drafted about 62 percent; the rest are code-set
labels. Code computed 100 percent of the numbers, and the renderer drew every
chart and graphic. The generative surface is enumerable, which is what makes
the output auditable: a reviewer can point at any element and say which worker
produced it.

**Language reuse across briefings, August 2026 run set.** Cross-narrative
5-gram Jaccard overlap between any two of the three briefings measured 3.4
percent, and every shared 8-gram was a data artifact such as a source URL or a
citation line, not template language. The contract constrains form without
leaking phrasing.

## The reproducibility test, in three covers

The three briefings the document compares in section 07 were produced by the
same prompts, contract, validators, and renderer, and each cover already shows
the run's character: a one-line read that differs per programme because the
evidence differs, and the same printed caveat naming the one roster not yet
published.
