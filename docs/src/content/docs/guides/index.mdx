This tier does the task. Each guide is a recipe with exact commands, what
success looks like, and what each failure means. There are no teaching detours:
every guide closes with a short "What you just exercised" line linking the
concepts the task touched, and the theory stays in [Concepts](../concepts/).

Contributor setup (linking the rib into a local keelson checkout, the pre-PR
checks) lives in the repo's CONTRIBUTING.md, not here.
