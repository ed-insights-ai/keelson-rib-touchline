# Touchline

Touchline is a Keelson rib for college soccer season intelligence: on-demand
collection, verification, and reporting. The rib owns the capability —
workflows, tools, and surfaces — while all durable data (raw HTML cache,
parquet, observation ledger, reports) lives in a consumer-owned data repository
registered as the Keelson project the workflows run against.

Conference scope is configuration, not identity: the first deployment covers
the GAC, and schools/conferences are defined per data repo.

The original product and implementation contract lives in the
[Touchline rib specification](https://github.com/ed-insights-ai/ed-insights-platform/blob/main/docs/specs/touchline-rib.md).
